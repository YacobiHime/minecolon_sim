### LLM で発言する市民を何人動かせるか(初回の実測、2026-10-30)

条件: 推論は llm-server の llama-server(masbot と共用、GPU 1枚、Gemma 4 26B-A4B Q4_K_M、同時処理4件、MoE の一部を CPU に置く設定)。測定は PR #10 の `chat_capacity_bench.js`(マージ前のブランチ)。発言は40字以内の一言、出力の上限60トークン。ゲームは panama のスーパーフラット、コロニー1つ、自動倍率。

- **実際のゲームでの会話**(市民どうしが直前8行を読んで返す、各市民20秒に1回が目標、各段階2分、ゲーム内チャットへ出力):

| 人数 | 目標に対する発言の割合 | 応答時間 p95 | 判定 |
| --- | --- | --- | --- |
| 8 | 98% | 2.0秒 | 合格 |
| 32 | 88% | 4.1秒 | 不合格(割合が90%未満) |
| 64 | 41% | 4.2秒 | 不合格 |
| 96 | 27% | 4.4秒 | 不合格 |

  - 実際の処理量は毎秒約1.4発言(応答 約2.9秒 × 同時4件)。20秒に1回なら約28人、30秒に1回なら約42人が目安。
  - 540行の発言がゲームに届き、コンソールのエラー(`<--[HERE]`)は0件。
- **推論の速さの測定(throughput モード)は過大だった**: 毎秒約4.5発言と出たが、同じ依頼文を繰り返すため llama-server のプロンプトのキャッシュが効いていた。実際の会話では毎回文章が違い、同時4件のときの生成も遅い(16トークンに約1.9秒)。throughput モードは依頼文を毎回変える必要がある(PR #10 への指摘)。
- **市民の数とサーバーの重さ**(LLM なし、`/spawnCitizen` で増やした家も仕事もない市民、各段階90秒):

| 市民 | 1 tick の処理時間 | 自動倍率 |
| --- | --- | --- |
| 50 | 0.5ms | 40倍 |
| 100 | 0.9ms | 40倍 |
| 200 | 1.7ms | 21倍 |
| 300 | 2.6ms | 13〜14倍 |
| 400 | 3.9ms | 9倍 |

  - 働いていない市民なので、実際のコロニーより軽い。働く市民での測定は別に要る。
- **60秒に1回・60人**(ユーザーがゲームに入って確認): 約8分で497発言、失敗0、応答 p95 3.1秒。会話はチャットで読める速さ(約1行/秒)。ユーザーが確認したので停止した。

- 未実施: モデルの大きさ別の比較(E4B は llm-server にあるが、入れ替えると masbot が止まる)、GPU を増やした場合、alexandria への移設(12章の申し送り)。

- 比べたもの: AgentSociety、Generative Agents、OASIS、Concordia、Project Sid(PIANO)、Humanoid Agents、Sotopia、PersonaHub、PersonaLLM、Park 2024(1,000人)。
- 分かったこと: 会話の測定スクリプト(PR #10)は、8月に作ったペルソナの部品(`personas.js` の気質・話し方、`social_cognition.js` の欲求の優先度、`social_dynamics.js` の相手別の信頼・好意・恩・恨み)をまったく使っていない。濃いペルソナの大部分は、新しく作らなくても、今ある部品を文章にしてプロンプトに入れれば作れる。
- 提案された段階: 第1段=プロフィール・欲求・自分の気分・相手との関係を文章で入れる(LLM の呼び出しは増えない)。第2段=出来事の記憶(ルールで重要度)と、非同期の内省(20発言に1回など)。
- 提案された実験: A(今の薄いペルソナ)/B(第1段)/C(第1段＋記憶と内省)を、固定した8人・台本の出来事・seed 5通りで比べる。指標は語彙の多様さ、誰の発言かを当てる一貫性、相手への応答、感情の幅、関係が言い方に出るか、出来事への反応、日本語の自然さ。判定は生成と別のモデルで行う。GPU 1枚で全条件 約1.5時間(見積もり)。
- 状態: ユーザーに計画として示し、了承待ち。`personas.js`・`social_*.js` は読むだけで、変更しない予定(変更が要るならユーザーに確認する)。

### ペルソナの比較実験 A/B(2026-10-30、ユーザーの判断「まずは A と B」)

- 条件: PR #12 の `persona_chat_experiment.js`(マージ前のブランチ)。固定した8人、台本の出来事3つ(食料不足・家の完成・ゾンビの夜)、seed 1〜5、各会話360発言、2本並行。推論は llm-server(Gemma 4 26B-A4B、masbot と共用、SSH トンネル経由)。ゲームには出していない。
- A = 今の薄いペルソナ(名前・仕事・一言の性格)。B = 第1段(8月の部品から、人物像・欲求・気分・相手との関係を文章にして入れる。LLM の呼び出しは増えない)。**AgentSociety のプログラムは使っていない**(項目の立て方を参考にしただけ)。記憶と内省(条件 C)はまだ。
- 結果(平均 ± 標準偏差、各 n=5):

| 指標 | A | B |
| --- | --- | --- |
| 名前を呼んで返す発言の割合 | 0.07 ± 0.02 | 0.41 ± 0.03 |
| 2人のやりとりの連鎖(会話あたり) | 0 | 6.8 ± 2.7 |
| 出来事への反応(3つの平均) | 0.49 ± 0.14 | 0.71 ± 0.08 |
| 家の完成への反応 | 0.25 | 0.65 |
| ゾンビの夜への反応 | 0.45 | 0.70 |
| 恩のある相手へ話しかけた回数 / 好意的な言い方の割合 | 1.6 / 0 | 35.4 / 0.27 |
| 恨みのある相手へ話しかけた回数 | 0.8 | 13.6 |
| 語彙の多様さ(distinct-2) | 0.27 | 0.23 |
| 重複率 / 途中で切れた率 | 0.002 / 0 | 0.032 / 0.009 |
| 平均の長さ(字) | 26.0 | 29.8 |

- 判断: B は相手に向けて話し、関係や出来事が発言に出る。一方で語彙の多様さはやや下がり、重複も増えた(人物像の決まり文句を繰り返す傾向)。指標はすべて規則ベースで、自然さや一貫性の LLM 判定はまだ(判定に使うモデルが未決定)。
- 生データ: panama のスクラッチパッド(`persona_ab/`)。リポジトリには入れていない。
