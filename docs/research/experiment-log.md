## 実験 B-1(2026-10-30)

- 目的: 一関駅の周りを Arnis で Minecraft のワールドに変換し、研究室の環境(Java 1.20.1、Forge 1.20.1-47.1.30、MineColonies 1.20.1-1.1.1231)で開けるかを確かめる。
- 条件:
  - ツール: Arnis v3.3.0(GitHub のソースから GUI なしでビルド。`cargo build --release --no-default-features`)。置き場所は panama の `/opt/arnis-src`。
  - 範囲: 一関駅(OpenStreetMap の駅の位置、北緯 38.92688・東経 141.13890)を中心に 500m 四方。`--bbox 38.92464,141.13601,38.92913,141.14179`。
  - 縮尺: 1ブロック = 1m(`--scale 1`)。そのほかは既定値(地形あり、建物の足りない分を Overture Maps で補う、内装なし)。
  - 標高: Arnis 既定の Mapterhorn。国土地理院のデータが使われたかは未確認。
  - 開いた環境: 本番とは別の試験用サーバー(`/root/mc-server-forge/test-instance`、ポート 25566、ブリッジの MOD なし、MineColonies ほかの MOD はあり)。
  - 時間の速さ: 試験用サーバーは倍率の変更なし(1倍)。
- 手順:
  1. `arnis --bbox ... --output-dir /root/mc-server-forge/arnis_out --scale 1` で変換した(約7秒)。
  2. 出来たワールドを試験用サーバーにコピーし、起動した。
  3. ワールドのブロックの種類(パレット)を全部取り出し、1.20.1 のブロックの一覧と照らし合わせた。
- 結果:
  - 出来たワールドは 1.21.4 の形式だった(`level.dat` の DataVersion 4189、チャンクの DataVersion 3955)。1.20.1 は 3465。
  - 試験用サーバーは、エラーなしで起動し、出現地点の周りのチャンクを読み込んだ(MineColonies を含む MOD との衝突のログもなし)。
  - 使われているブロックは160種類。そのうち 1.20.1 にないのは `minecraft:short_grass`(1.20.3 で `grass` から改名)だけで、1.20.1 では空気になる(草むらが消える)。
  - 範囲の標高差は 3.1m。駅前は平らだった。
  - ワールドの大きさは 4.2MB(リージョンファイル1つ)。
- 判断: 新しい版のワールドでも、ほぼそのまま 1.20.1 で開ける見込み。サーバーに MOD を足す必要はない。実験計画の判断の基準のうち「1.20.1 で使えるか」は満たしそう。再現の出来(地形・川・線路・道路・建物)は、ゲームに入って見るまで判断しない(B-2 で行う)。
- 分かった仕様: (MineColonies ではなく Minecraft の版の話)1.21 系で書かれたチャンクを 1.20.1 の Forge サーバーが読み込める。改名されたブロックだけが失われる。
- 注意: OpenStreetMap のデータを使っているので、画像や発表では出典(© OpenStreetMap contributors)を示す。自宅の位置が分かる範囲は使わない。
- 次にやること:
  - B-2: ユーザーがゲームに入り、現実の地図と並べて再現の出来を見る。
  - 草むらを残したい場合は、`short_grass` を `grass` に書き換える変換を入れる。
  - 磐井川が 500m 四方に入っているかを確かめる。入っていなければ範囲を広げる。

## 実験 B-2(2026-10-30)

- 目的: B-1 で変換したワールドの再現の出来を、ゲームに入って現実の地図と比べる。分かりにくい点を後処理で直せるかを試す。
- 条件: B-1 と同じワールド(一関駅の周り 500m 四方)。後処理ツール `tools/map_import/arnis_post.py`(PR #11、マージ前のブランチ)。試験用サーバー(ポート 25566)。
- 手順:
  1. ユーザーがゲームに入り、西口(x=142, z=317 付近)などを見た。
  2. 道路と周りの地面の表面のブロックを調べた。道路の線の上は灰色のコンクリートパウダー・青緑がかった灰色のテラコッタ・灰色のコンクリートで、周りの市街地の地面(石レンガ・薄灰色のコンクリートなど)と色が近い。範囲内の道路で幅や車線数のタグがあるのは1本だけ。
  3. 後処理の4案を作り、真上からの画像で比べた: 道路の色だけ黒くする(recolor)/OSM の道の種類ごとの幅で描き直す(redraw)/描き直し＋地面を明るくする/描き直し＋地面を草地にする。
  4. recolor(＋改名された草むらの修正)を試験用サーバーに入れ、ユーザーが見た。
- 結果:
  - ユーザーの最初の評価は「あまり再現度は高くない、道路がもう少し分かりやすいとよい」。
  - recolor は、道路が黒くなり白線が残るので、街区の形が見やすくなった。道路の約2.4万列を変更、1回の後処理は約3秒。
  - redraw は、OSM に幅の情報がほとんどないため決め打ちの幅になり、Arnis の灰色の道路が新しい道路の脇に残る。草地にする案は、駅の線路の敷地まで芝生になる。
  - 500m 四方には磐井川は入らない(駅から西北西に約850m)。駅の東側を流れる別の川は入っている。磐井川まで入れた広い範囲(西へ1000m・東へ300m・北へ500m・南へ300m、1299×800 ブロック、高低差77m)も Arnis で生成済み(`/root/mc-server-forge/arnis_out_wide`)。
- 判断: **recolor を採用**(ユーザーの判断「この感じでいいんじゃないかな」)。
- 分かった仕様: (Minecraft・Arnis の話)Arnis は市街地の地面を石レンガ系で埋めるため、道路との差が小さい。OSM の日本の地方都市では道路の幅のタグがほとんどない。
- 注意: 画像を外に見せるときは「© OpenStreetMap contributors」を付ける。
- 次にやること: 変換したワールドに MineColonies のコロニーを作り、建物を置けるかを試す(実験計画 B の手順4)。広い範囲のワールドにも recolor をかける。
